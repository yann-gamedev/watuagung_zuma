# Progres 5 November 2026 — R8 video profil dan tutorial

Branch `feat/site-content-videos` dari `origin/main` `2600a2e` (local `main` sudah tertinggal, disamakan ke `origin/main` sebelum membuat branch).

## Lingkup

Video profil desa dan video tutorial pengajuan surat diambil dari YouTube dan diatur dari panel. Key `videos` di `site_sections` kini punya skema; `statistics` tetap menolak semua PUT (R5).

## File yang diubah

- `backend/app/Domain/SiteSectionRules.php`: aturan `videos`. Body PUT `{ profile: { url, title } | null, tutorial: ... }`, field asing ditolak, `url` ≤2.048, `title` 1–160, kontrol ditolak. `youtubeId()` mengekstrak ID 11 karakter dari youtube.com/www/m `watch?v=`, `/shorts/`, `/embed/`, dan `youtu.be/`; URL lain 422 `data.<slot>.url`. Hanya `{ youtubeId, title }` yang disimpan. Key lain tidak berubah.
- `backend/tests/Feature/SiteSectionsApiTest.php`: 4 tes baru (round trip + audit + key lain tetap, bentuk URL diterima/ditolak, skema/batas/kontrol, tanpa token/peran salah/ability salah); tes key cadangan kini hanya `statistics`.
- `types/site.ts`, `types/pelayanan.ts`: `SiteVideo(s)`, `SiteVideo(s)Input`, `SiteSectionInput`; `videos` masuk `EditableSiteSectionKey`; `SiteSectionUpdate` memakai bentuk input.
- `lib/youtube.ts` (baru): parser cermin server + URL gambar mini/embed/watch. `lib/data.ts`: cadangan `videos` keduanya null.
- `services/site.ts`: `videosSchema` (respons), `videosInputSchema`/`siteInputSchemas` (body PUT; link+judul kosong = null).
- `features/admin/site-form.tsx`: kerangka R4 menerima tipe input terpisah (`prepare` data → isian). Untuk key lain input = data, perilaku sama.
- `features/admin/video-editor.tsx`, `app/admin/konten/video/page.tsx`, `site-content-list.tsx`, `admin-sidebar.tsx`: panel dua kartu (link, judul, pratinjau, Hapus video), hanya admin/staff.
- `components/youtube-embed.tsx`, `components/site-video.tsx`, `app/page.tsx`, `components/site-text-page.tsx`, `app/pelayanan/page.tsx`, `app/globals.css`: komponen bersama dan penempatan. Tata letak profil hasil redesain tidak diubah; video ditambahkan di atas bento.
- `scripts/test-site.mjs`: parser, skema, fallback, PUT link.
- `docs/integrasi.md`, `backend/README.md`, `docs/deploy-plan.md` (CSP `frame-src https://www.youtube-nocookie.com`, `img-src https://i.ytimg.com`), `ROADMAP.md`.
