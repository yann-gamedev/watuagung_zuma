Baru: `contact-editor.tsx` (enam field + petunjuk + pratinjau peta iframe 4:3 maks 400px), `site-content-list.tsx` dan halaman `app/admin/konten/` + `app/admin/konten/kontak/`. Sidebar menambah "Konten desa" (`FileText`); item profil/sejarah tetap.
- **Publik**: `components/contact-provider.tsx` (satu fetch per halaman) membungkus `PublicShell`; `components/office-contact.tsx` menyediakan `useContact`, `ContactAddress`, `ContactHours`. Footer, header/menu, panel tugas, dan kebijakan privasi memakai context. Nilai awal tetap `lib/data.ts` sehingga HTML statis dan demo tidak berubah.
