## R7 — Bagan struktur pemerintahan

Branch `feat/site-content-structure`, basis `ba3d5d9`. Tanpa Boost/dependensi baru, push, deploy, perubahan `.env`, atau data warga.

### Perubahan

- `backend/app/Domain/SiteSection.php`, `SiteSectionRules.php`, `SiteSectionController.php`: gambar hanya untuk structure; skema ketat `{chartImagePath?, chartAlt?, blocks, source}`. Blocks 1–20, judul ≤160, teks ≤10.000; sumber wajib ≤1.000; deskripsi ≤300 wajib bila gambar ada. Unknown fields/kontrol ditolak; CR/LF hanya teks blok. Tanpa gambar, chartAlt kosong boleh, null ditolak.
- POST `/staff/site/structure/image` memakai ImageProcessor yang sama, ≤5.120 KiB, dimensi input 600×400–6.000×6.000, output lebar ≤2.400 tanpa upscale; encode ulang WebP/JPEG tanpa metadata. UUID folder public `site/structure`, respons `{path,url}`. PUT menerima format path hasil unggah dan file harus ada; GET/PUT menambah `image_url` nullable di luar data.
- PUT structure memakai lock per host sampai cleanup; gambar lama dihapus setelah commit pergantian/penghapusan, tetap ada bila validasi/audit gagal. Key lain/berita tidak berubah. `SiteSectionDefaults` dan command impor menambah key kelima, blok/sumber sama dengan `lib/data.ts`; idempoten.
- `types/site.ts`, `types/pelayanan.ts`, `services/site.ts`: kontrak structure, Zod ketat, envelope gambar dan multipart. `features/admin/structure-editor.tsx`, `app/admin/konten/struktur/page.tsx`, daftar konten/judul panel: pratinjau, unggah/ganti/hapus, deskripsi pembaca layar, editor blok nama/jabatan dan sumber. Kerangka SiteForm R4 mempertahankan pesan simpan/galat/peringatan keluar; formulir terkunci selama unggah.
- `components/structure-page.tsx`, `app/[slug]/page.tsx`, `lib/data.ts`: blok/sumber statis tampil dulu, API browser mengganti bila valid. Gambar opsional sebelum daftar teks; Perbesar gambar membuka file di tab baru. Tanpa HTML mentah/lightbox/dependensi. Tata letak profil, visi-misi, kontak tidak disentuh.
- `SiteSectionsApiTest.php`, `scripts/test-site.mjs`: auth/peran/ability, skema/kontrol/batas, impor, unggah berhasil/gagal, resize, path, cleanup/rollback, lock, regresi key lain, transport/fallback dan validasi frontend. Dokumentasi kontrak/deploy/ROADMAP diselaraskan.
