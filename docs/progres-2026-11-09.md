# Progres 9 November 2026 — peran KIM

Branch: `feat/role-kim`. Lingkup disetujui: KIM hanya mengelola berita dan UMKM; tidak ada push/deploy.

## Perubahan

- Backend: `User::abilities()` menjadi sumber pemetaan `panel`, `applications:manage`, `media:manage`, dan `site:manage`. Login menerbitkan token sesuai peran; `/staff/me` mengirim `abilities`. KIM menerima `panel` dan `media:manage` saja.
- Route pelayanan tetap memakai `applications:manage`, termasuk `/staff/users…` yang juga diperiksa khusus admin oleh controller. Berita/UMKM memakai `media:manage`, konten situs memakai `site:manage`. Pemeriksaan peran/akun aktif tetap lapisan kedua; scope data pelayanan menolak KIM. Ability diperiksa sebelum model binding agar penolakan tidak membocorkan keberadaan data lewat 404. Galat GET panel memakai `private, no-store`.
- Frontend: profil memvalidasi abilities, helper `can()` dan guard route bersama membatasi menu serta pemasangan komponen anak. KIM membuka `/admin/berita/` saat masuk `/admin/`; route terlarang menampilkan pesan tidak tersedia dan tautan Ke Berita tanpa memuat data pelayanan. Label KIM dan keterangan batas peran ditambahkan pada pengelolaan akun. Aksi akun sendiri tetap tersedia.
- Kontrak/dokumentasi: `types/pelayanan.ts`, `PRODUCT.md`, `docs/integrasi.md`, `backend/README.md`, dan kebijakan privasi menjelaskan batas KIM. Kontak pemilik UMKM tetap tersedia pada detail panel berwenang; izin publik tetap wajib untuk menampilkannya kepada pengunjung.
- Regresi: `KimRoleTest` membaca route terlarang dari router, menguji penolakan dengan record nyata dan ability berlebih, CRUD/foto/audit media, kompatibilitas peran lain, penonaktifan, serta pencabutan token lama. Fixture seluruhnya fiktif.

Database SQLite fiktif dan salinan frontend berada di direktori temp, terpisah dari database/server pengembangan yang sudah ada. Frontend port 3001 memakai webpack karena Turbopack menolak junction dependensi pada salinan sementara; backend port 8010. Tidak mengubah konfigurasi repo untuk E2E.

- Admin membuat akun KIM dari panel; KIM masuk memakai kata sandi sementara dan berhasil menggantinya.
- `/admin/` mengalihkan KIM ke Berita. Navigasi hanya Berita dan UMKM; label `KIM (Media Informasi)` tampil, aksi akun sendiri tetap ada.
- KIM menerbitkan berita dan UMKM fiktif; pesan berhasil tampil.
- `/admin/permohonan/` menampilkan `Halaman ini tidak tersedia untuk peran Anda.` dan Ke Berita. Resource halaman hanya memuat `/staff/me`, tanpa request applications/summary.
- Request KIM langsung ke `/api/v1/staff/applications` menghasilkan 403 dengan `Cache-Control: no-store, private`.
- Iframe same-origin 390px dan 1440px: lebar dokumen sama dengan viewport, tautan navigasi hanya Berita/UMKM. Desktop sidebar berada di kiri 0. Mobile `data-open=true` dan latar inert; animasi berhenti pada waktu 0 ketika tab tidak terlihat. Setelah animasi diselesaikan lewat API browser, sidebar berada di kiri 0. Ini pengukuran DOM, bukan pemeriksaan visual atau bukti animasi normal pada tab terlihat.
