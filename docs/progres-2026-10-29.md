## Perubahan

- `backend/app/Http/Controllers/Api/PostController.php`: POST/DELETE sampul; hak kelola `User::canManageContent()` sama dengan C1; validasi file JPG/JPEG/PNG/WebP ≤ 3.072 KiB, lebar 600–6.000 dan tinggi 400–6.000 px. GD menggambar ulang piksel ke kanvas baru, memperkecil lebar maksimal 1.600 tanpa memperbesar, rasio tetap; WebP kualitas 80 atau JPEG kualitas 82 (transparansi putih). File asli/EXIF/GPS tidak disimpan. UUID di disk public `posts/`. GD hilang → 503, gambar tidak terbaca → 422.
- Penggantian path dan audit `post.updated` memakai transaksi + penguncian baris. File baru ditulis dahulu; gagal DB membersihkan file baru dan mempertahankan sampul lama. File lama dihapus setelah commit; gagal hapus memberi 500 dengan keterangan bahwa sampul sudah diperbarui. DELETE sampul mengembalikan detail dengan `cover_url=null`; soft delete berita tidak menghapus file.
- `backend/routes/api.php`: dua route baru berbagi throttle 10/menit per akun dengan prefix `post-cover`, terpisah dari throttle lain.
- `backend/config/filesystems.php`: URL disk public dari `MEDIA_URL`, kosong/tidak diisi memakai `${APP_URL}/storage`. Produksi `MEDIA_URL=https://[DOMAIN]/media` sehingga URL `/media/posts/<uuid>.webp` atau `.jpg`. Tidak mengubah file env; konfigurasi dijelaskan di dokumentasi.
- `backend/tests/Feature/PostCoverTest.php`: 25 kasus, termasuk input keempat format, tipe/ukuran/dimensi salah dan batas valid, resize/tanpa upscale, EXIF dan GPS fiktif valid yang dibuat dalam tes, penggantian/penghapusan, soft delete dan restore, otorisasi, throttle, URL publik/petugas, audit tanpa isi, dan rollback DB. Pemeriksaan GD/WebP memberi skip dengan pesan jelas bila tidak ada.
- `types/posts.ts`, `types/pelayanan.ts`: kontrak multipart dan respons detail; tidak mengubah UI.
- `docs/integrasi.md`, `backend/README.md`: kontrak, konfigurasi URL, siklus file, keterbukaan file publik.
- `docs/deploy-plan.md`: kebutuhan php-gd dengan JPEG/PNG/WebP pada CLI/FPM; alias Nginx hanya `/media/posts/`, tanpa eksekusi PHP, cache panjang dan nosniff; path persisten/hak akses; backup dan restore media. Butir infrastruktur tetap belum dicentang. Hanya subbutir API C2 yang sudah diverifikasi dicentang, juga di `ROADMAP.md`.
