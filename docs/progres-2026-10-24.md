## Perubahan

- `backend/config/app.php`: timezone membaca `APP_TIMEZONE`, bawaan `Asia/Jakarta`; komentar disesuaikan.
- `backend/.env.example`: menambahkan `APP_TIMEZONE=Asia/Jakarta`. Tidak membaca/mengubah `.env`, tidak membuat/mengubah/mencetak nilai APP_KEY, tanpa dependensi baru.
- `backend/tests/Feature/LetterRegisterTest.php`: dua tes menggunakan `travelTo(Carbon::parse(..., 'Asia/Jakarta'))`, tanpa memaksakan timezone konfigurasi di tes. Tanggal 31 Desember 2026 pukul 23.59 WIB memakai tahun 2026; tanggal 1 Januari 2027 pukul 00.01 WIB kembali ke urutan 1 setelah dua nomor tahun lama. Memeriksa waktu tersimpan, filter tahun bawaan register, serta timestamp register/riwayat API yang mewakili instan WIB tersebut.
- `docs/integrasi.md`, `backend/README.md`: mengganti keterangan timezone lama; serialisasi API tetap ISO 8601 UTC, bukan perubahan kontrak. `types/pelayanan.ts` tidak perlu berubah.
