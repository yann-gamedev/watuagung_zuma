# S4 — Panel petugas enam jenis surat final (8 November 2026)

Branch: `feat/letters-final-admin` (dari `feat/letters-final-form`). Tidak mengubah backend, kontrak API, template PDF (S2), atau formulir warga (S3).

## Perubahan

- `features/admin/application-detail.tsx`: "Data diri" memuat field baru dan Dusun. Agama dan status perkawinan disamarkan; tombol **Tampilkan** memuat ulang `GET /staff/applications/{id}` (tercatat audit `application.viewed` yang sudah ada) dan nilai baru tampil setelah permintaan berhasil. NIK/KK tetap tampil penuh sesuai `DESIGN.md`. "Detail permintaan" per jenis: barang hilang, data acara, isi keterangan + keperluan.
- UMUM: petugas/admin dapat menyunting **Isi keterangan yang dicetak** selama server mengirim `can_edit_isi_keterangan` (sampai `WAITING_APPROVAL`). Tombol **Simpan kalimat**, validasi Zod 2–500 karakter, `PATCH /staff/applications/{id}/isi-keterangan`; gagal simpan mempertahankan teks. Teks asli warga ditampilkan di bawahnya. Selama ada perubahan belum disimpan, aksi status dan **Lihat draf PDF** dinonaktifkan dan `beforeunload` memberi peringatan. Riwayat `STATEMENT_EDITED` tampil sebagai "Isi keterangan disunting".
- Hasil review diperbaiki: gagal simpan memuat ulang detail agar tombol tidak macet bila status berubah oleh petugas lain; pesan "Simpan kalimat" di tombol draf hanya muncul bila ada kalimat belum disimpan; spasi di ujung tidak dihitung sebagai perubahan; textarea `readOnly` saat menyimpan agar fokus tidak hilang; `aria-pressed` dihapus dari tombol Tampilkan/Sembunyikan; "Kembali ke daftar" meminta konfirmasi bila kalimat belum disimpan.
- `features/admin/application-detail.module.css`: gaya `.sensitive` dan `.statement` memakai token yang ada.
- `features/admin/application-filters.ts`: label bersama untuk filter, daftar, ringkasan dasbor dan register: enam jenis final dulu, lalu SKU/KTP_KK dengan akhiran `(jenis lama)` agar data lama tetap terbaca.
- `scripts/test-admin-filters.mjs`: assertion urutan, label dan round-trip filter.
- `scripts/test-final-letter-admin.mjs` (baru): E2E lokal Chrome headless (CDP) + static export + Laravel dengan SQLite terpisah. Butuh `ADMIN_TEST_DIR` dan `ADMIN_TEST_TOKENS`; tidak dijalankan di CI.
- `docs/integrasi.md`: catatan panel S4 dan penyamaran.
