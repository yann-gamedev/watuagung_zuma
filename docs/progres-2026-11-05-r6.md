Suite backend dijalankan bergantian. Percobaan PostgreSQL pertama gagal `could not find driver`; diulang dengan `PHP_INI_SCAN_DIR` sementara memuat DLL `pdo_pgsql` yang sudah terpasang, APP_KEY lokal diwariskan di memori tanpa dicetak/diubah. Hasil akhir tabel di atas lulus. Tes awal menemukan `documentPath: ""` lolos; aturan ditambah `required` bila field hadir. Kasus float tahun diganti 2027.5 karena JSON encoding PHP mengubah 2027.0 menjadi integer 2027.

Review akhir menemukan race validasi/penghapusan PDF pada dua PUT bersamaan. Diperbaiki dengan `flock` per host yang meliputi validasi, simpan/commit, dan cleanup. Tes regresi proses PHP kedua memegang lock, menghapus PDF, lalu melepas lock; PUT menunggu dan menolak referensi yang sudah hilang (422), bukan menerbitkan tautan mati. Lock tidak mengubah key lain. Suite SQLite/PostgreSQL diulang setelah perbaikan, hasil akhir pada tabel. Deployment multi-host perlu lock bersama sebelum memakai disk bersama.

Tes upload mencakup sukses, 401, peran salah 403, file hilang/non-PDF/>10 MiB 422, batas tepat 10 MiB, key lain ditolak. Tes PUT mencakup total klien, tipe/rentang/jumlah, urutan bidang, dokumen tidak ada, pergantian/penghapusan file, serta audit gagal tidak menghapus dokumen lama.
