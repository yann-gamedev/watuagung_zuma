Profil lama tanpa details tetap valid; `history` menolak field ini. `SiteSectionDefaults` mengikuti `lib/data.ts` terbaru, termasuk details dan blok wilayah tanpa "±11 km". Tes `SiteSectionsApiTest` ditambah (batas panjang/jumlah, tipe, field asing, kontrol, arah tetap, impor).
- **Kontrak**: `types/site.ts` (`SiteProfile`, `SiteProfileDetails`); `services/site.ts` skema Zod ketat + `getSiteSection()` (browser, `no-store`, timeout 20 detik, tanpa token, `null` untuk demo/404/galat/format salah).
- **Panel**: `features/admin/site-editor.tsx`, halaman `app/admin/konten/{profil,sejarah}/`, tautan sidebar untuk admin/staff. Penjaga perubahan belum disimpan dipindah ke `features/admin/use-unsaved-changes.ts` dan dipakai bersama editor berita. Lembaga/angka/blok bisa ditambah, dihapus, dan diurutkan dengan tombol Naik/Turun.
- **Publik**: `components/site-text-page.tsx` merender data statis dulu lalu mengganti dengan data API. Peta, markup bento, dan CSS tidak diubah. Teks bawaan pertama tetap dipotong sebelum " Pertanian,"; teks hasil suntingan tampil utuh. Tema ke-4–6 memakai ikon `Sprout`; blok setelah ke-3 tampil sebagai `content-card` biasa.
